DIAGRAMS the project's visual library

Every diagram this project makes lives here. Click a card to open it full window on an infinite canvas: pan anywhere, zoom as far as you need, and the text stays sharp. To add a diagram, file its SVG in diagrams/svg/ and add one entry to diagrams/diagrams-data.js; the page does the rest.

VIEWER KEYS inside a full-size diagram

Pan drag, two-finger scroll, or arrow keys
Zoom pinch, ⌘ + scroll, double-click (Shift + double-click zooms out), or + and -
Fit 0 or the FIT button · Actual size 1 or the 1:1 button · Close Esc
